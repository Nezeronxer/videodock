# VideoDock

Что сделать: открытый настольный загрузчик для Linux, macOS и Windows, с рабочей загрузкой видео/аудио, очередью и историей. REA используется для изучения поставки 4K Video Downloader+, код и ресурсы оригинала в приложение не переносятся.

Объём: первая рабочая версия. Python 3.12, Qt Widgets (PySide6 Essentials), yt-dlp, внешний FFmpeg. Проверка: pytest, реальная загрузка и ffprobe, интерфейс Qt, линтер, аудит зависимостей и исходников, сборка Linux. macOS/Windows требуют запуска на соответствующих ОС.
