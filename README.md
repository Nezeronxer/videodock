# VideoDock

Открытый настольный загрузчик видео и аудио для Linux, macOS и Windows. Первая версия: ссылки HTTP(S), очередь, качество до 4K, MP3, плейлисты по флажку, субтитры RU/EN, отмена и повтор, история, выбор папки, необязательный прокси. Сайты поддерживает yt-dlp; доступность конкретного сайта зависит от его текущих ограничений.

Интерфейс и логика приложения написаны отдельно. Исследование установленного 4K Video Downloader+ через REA описано в [docs/rea-findings.md](docs/rea-findings.md). Код, иконки и другие ресурсы оригинала не входят в приложение.

## Запуск из исходников

Нужны Python 3.12+, FFmpeg в PATH и Node.js для JavaScript-проверок YouTube. Зависимости Python запускальщик устанавливает в пользовательское окружение вне папки проекта.

```sh
python scripts/run.py
```

На Linux/macOS команда Python может называться `python3`. На Windows - `py -3.12`. Установка ярлыка Linux или приложения в `~/Applications` macOS:

```sh
python scripts/install.py
```

Системные зависимости:

- Arch: `sudo pacman -S python ffmpeg nodejs`.
- macOS: `brew install python ffmpeg node`.
- Windows: Python с python.org, FFmpeg с ffmpeg.org и Node.js с nodejs.org; добавить в PATH.

Без прокси используется прямое подключение. Для SOCKS укажи, например, `socks5://127.0.0.1:1080`. Учётные данные прокси и импорт браузерных cookies в этой версии не поддерживаются. Приложение не меняет настройки zapret/VPN.

Формат видео сохраняется в исходном контейнере; при объединении отдельных видео/аудио используется MP4. Ограничение качества - верхняя граница при наличии сведений о разрешении. Без флажка плейлиста его отдельный адрес загрузит только первый элемент; ссылка на видео внутри плейлиста загрузит это видео. Отмена оставляет `.part`; продолжение зависит от сервера. В записи плейлиста кнопка «Открыть» открывает последний сохранённый файл, «Папка» - каталог остальных.

## Данные

Настройки и история находятся в стандартном локальном каталоге Qt для `Nezeronxer/VideoDock`, отдельно от исходников и папки загрузок. База не синхронизируется между компьютерами. Можно выбрать общую папку готовых файлов в Dropbox. «Убрать» удаляет только запись истории. После перезапуска незавершённые задания требуют явного повтора.

## Разработка и сборка

```sh
uv sync --locked
uv run pytest -q
uv run ruff check .
uv run python scripts/build.py
```

Чтобы держать venv вне Dropbox, задай `UV_PROJECT_ENVIRONMENT` на локальный каталог. В текущей Linux-установке он в `~/.local/share/videodock/venv`.

Сборка выполняется на целевой ОС и включает GUI и отдельный worker. Результат лежит в пользовательском кэше `videodock-build/dist`; FFmpeg и Node.js не включены. Для распространения вместе с Qt необходимо сохранить его лицензии и выполнить условия LGPL. Приложение имеет лицензию MIT; лицензии зависимостей действуют отдельно.

Фактически выполненные проверки и ограничения: [docs/verification.md](docs/verification.md). Реальный запуск macOS/Windows требует отдельной проверки; наличие общего исходника её не заменяет.
