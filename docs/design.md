# VideoDock - первая версия

Пользователь подтвердил свой открытый аналог 4K Video Downloader и Linux/macOS/Windows. Рабочее имя VideoDock. Программа получает HTTP(S)-ссылки, сохраняет видео либо MP3 в выбранную папку, показывает очередь и историю. Качество: лучшее доступное, 2160/1440/1080/720/480. Дополнительно: плейлисты по явному флажку, субтитры ru/en при наличии, необязательный прокси без учётных данных.

Подходы: собственные экстракторы; Qt + yt-dlp; форк стороннего клиента. Выбран Qt + yt-dlp: единый код для трёх ОС, готовые экстракторы, независимый интерфейс. Это проектное решение; статический разбор оригинала не доказывает его внутренние алгоритмы.

Состав: `core.py` - проверка настроек и SQLite; `worker.py` - отдельный процесс yt-dlp с JSON-событиями; `ui.py` - Qt-интерфейс и последовательная очередь; `__main__.py` - GUI/worker; `scripts/` - запуск, установка ярлыка, сборка. Настройки и SQLite лежат в системном каталоге приложения за пределами Dropbox; готовые файлы можно сохранять в Dropbox. Атомарность записей обеспечивает SQLite. Два экземпляра GUI не запускаются одновременно.

Безопасность: HTTP(S) без credentials/control characters; запрещены file/data/javascript URLs; proxy без паролей; shell-команд из входа нет; страницы и скрипты сайтов не попадают в UI как HTML; внешние сетевые слушатели отсутствуют. Worker использует приватные стандартные каналы. Для загрузок разрешён доступ к введённому адресу и его медиасерверам. Оригинал, его настройки, базы, учётные записи и лицензирование не изменяются.

Очередь работает по одному заданию. Отмена останавливает worker и дочерний FFmpeg, оставляя .part для повтора; повтор не запускается сам после перезапуска. Удаление из истории удаляет только запись. После аварии активные записи получают статус «Прервано». Ошибки сети показываются в карточке, следующие задания продолжаются.

Проверка: unit-тесты входа/SQLite/options; интеграционный HTTP fixture с реальным видео и FFmpeg; Qt-тесты добавления, завершения, отмены, повтора, перезапуска и ошибок; реальная внешняя загрузка при доступности сети; ffprobe; ruff; pip-audit; проверка исходников на секреты/опасные вызовы; Linux PyInstaller. Внешний browser/desktop доступ и реальные macOS/Windows здесь не предполагаются. Для этих ОС сохраняются воспроизводимые команды и CI, без утверждения о проверенном запуске.
