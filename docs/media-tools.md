# Изменение состава функций

04.11.2026 пользователь выбрал полное удаление ИИ-обработки медиа вместе с кнопками и моделями. Раздел Media Tools, его команды, очередь и загрузка моделей удалены из текущей версии.

Прежние результаты и пользовательские файлы сохраняются. Старая очередь обработки архивируется локально при миграции профиля и не попадает в публичный snapshot или экспорт. Обычная библиотека продолжает находить ранее созданные медиафайлы.

FFmpeg используется для скачанных дорожек: объединения, преобразования контейнера, субтитров и локальных превью. Подробности текущей проверки - в [проверке YouTube](youtube-delivery-2026-11-04.md).
