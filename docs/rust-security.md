# Проверка безопасности Rust-версии

03.11.2026, локальный настольный клиент. Область: собственные `crates/{media,core,desktop}`, Qt bridge, установочные скрипты и Cargo.lock. Проверены входные ссылки и названия, HTTP redirects/cookies, SQLite, импорт/экспорт, временные и готовые файлы, очередь/отмена, FFmpeg, модели. Проверки выполнялись на синтетических данных и localhost. Профили оригинального 4K/Chrome и реальные учётные данные не читались.

## Исправленные находки

| Находка | Причина и исправление | Воспроизведение и повтор |
|---|---|---|
| Подписанная ссылка попадала в имя файла и папку | Нумерация и отдельная папка строились из исходного title до очистки. Теперь title и entry.title маскируются в общей точке получения Media до любых производных полей. | Тесты `numbered_clipboard_filenames_never_persist_private_url_queries`, `playlist_title_cannot_leak_a_private_query_into_the_output_folder`; независимые проверки SQLite/snapshot до и после. |
| Битая symlink вызывала бесконечный retry сохранения | `exists()` принимал dangling symlink за свободное имя. Используется `symlink_metadata()`, цикл публикации проверяет отмену. | Unit `dangling_symlink_is_an_occupied_output_name`; независимый реальный pipeline сначала зависал, после исправления создаёт новый файл и сохраняет symlink. |
| Терялся срок cookie; устаревшая копия могла вернуться после запуска | Срок передаётся по всей цепочке Qt -> Rust -> HTTP. Cookies больше не сериализуются в отдельное хранилище; восстановление выполняет только собственный профиль Qt. | Unit expiry, Qt callback с expirationDate; независимый localhost Engine harness проверил истёкшую cookie, положительный контроль, истечение во время работы, restart, legacy JSON и новый replay. |
| Удаление выбранной записи могло очистить всю историю | AppDialog вручную повторял автоматическую связь DialogButtonBox -> Dialog. Второй accept отправлял уже очищенную selection; пустые ID означают ALL в core. Удалены повторные accept/reject handlers, в removeDialog выбранные ID фиксируются при открытии и очищаются перед dispatch; пустой набор не отправляется. | До исправления Qt+real Engine тест падал с `Confirmation dispatched an unscoped removal`. После исправления проверяет две завершённые загрузки, Cancel с флажком удаления файлов, сброс флажка при повторном открытии, изменение selection после открытия и повторный accept. Свежая независимая проверка `check-appearance.sh /tmp/videodock-independent-removal en`: exit0, соседняя запись и файл сохранены. |

Для каждой находки использованы отдельное обнаружение и свежая независимая проверка. Воспроизведения до исправления не выдаются за успешные тесты текущей версии.

## Автоматические проверки

- Gitleaks рабочего дерева - секретов не найдено. В истории из трёх коммитов предыдущий проход также не нашёл секретов. Четыре точных исключения в `.gitleaksignore` относятся к публичным continuation/entity metadata тестов RustyPipe; глобальных исключений каталогов нет.
- Semgrep: OWASP/security-audit/secrets rules, 51 правило, 53 файла, 0 findings; неполных разборов нет. Qt `.ts` - XML перевода, исключён из ошибочного TypeScript parser. Это не полное доказательство отсутствия уязвимостей Rust/Qt и не аудит всех vendored исходников. Второй движок секретов - Semgrep secrets; trufflehog отдельно не установлен.
- Cargo audit: 0 известных vulnerabilities и 0 unsound warnings после перехода на `wreq 0.16.3`/`lru 0.19`. Остаётся `RUSTSEC-2025-0057`: `fxhash 0.2.1` не поддерживается. Это предупреждение сопровождения, исправленной версии в advisory нет. TLS-библиотека обновлена вместе с wreq; её совместимость проверяется отдельно.

Приложение не публикует HTTP API, поэтому проверки страниц без входа и серверной многопользовательской авторизации здесь неприменимы. Произвольный HTTP(S)-адрес - явный вход локального загрузчика. FFmpeg запускается массивом аргументов и получает только локальные пути с ограничением протоколов; пользовательские строки не выполняются shell. Публикация результата не заменяет существующий файл. SQLite использует параметризованные значения. Cookies и приватные signed sources отсутствуют в публичном snapshot/экспорте.

Журналы и отдельный cookie harness: `~/.local/share/videodock/research/resume-2026-11-03/`. Материалы в `/tmp`, созданные до перезагрузки17:09, не сохранились; соответствующие исходные результаты отмечены в рабочем журнале, важные регрессии включены в репозиторий.

## Остаток

Не проверены Windows/macOS, реальные пользовательские аккаунты, все сайты и их layouts, длительные race/stress сценарии и весь native Qt/FFmpeg/TLS исходный код. Живой desktop walkthrough недоступен в текущем computer-use окружении. Исправленные находки не означают завершения полного соответствия оригиналу или готовности релиза.
