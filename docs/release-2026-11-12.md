## Сеть и границы

Обычный системный маршрут YouTube на этой машине проходит через Happ; флаг «без прокси» в программе не означает физический прямой путь. Более свежий сетевой отчёт от11.11 подтверждает выбор пользователя. Глобальные AI/Discord/браузерные маршруты не менялись. Для программы настроен отдельный loopback gateway поверх уже существующих локальных upstream: YouTube и проверка Google используют native ingress, остальные площадки - Happ. Это персональная настройка окружения, не зависимость поставляемого приложения и не скрытый fallback.

Настройка хранится в shared assets/videodock-routing и once jobs Linux/Darwin. Идемпотентность проверена без повторного запуска процесса. На macOS без эквивалентного native ingress установщик ничего не меняет; живой запуск Mac этим проходом не подтверждён.

Поддержка всех сайтов, аккаунтов, регионов, закрытых видео и всех дистрибутивов не заявляется. Файлы с подтверждёнными ошибками не выдаются за готовые; готовые пользовательские файлы не удаляются при очистке private staging.

## Время тестовых Windows-VM

Обнаружено несоответствие гостевых часов: UTC Windows10 был на11ч вперёд, Windows11 - на3ч. В libvirt использовался localtime хоста Europe/Moscow при гостевых Pacific Standard Time и UTC. RTC согласован с гостевыми зонами по [официальной документации libvirt](https://libvirt.org/formatdomain.html#time-keeping); резервные XML и команды rollback сохранены. После обычной загрузки Win10UTC14:28:06 и Win11UTC14:29:55 совпали с реальным временем. Лицензирование и активация не менялись. Сетевые прогоны с неверным UTC не считаются окончательной проверкой сроков подписанных ссылок.

Случай старых будущих created_at дополнительно воспроизведён падающими Core/Qt тестами. Исправление добавляет устойчивый added_order; исходные даты, ID и пути не переписываются. Копия реального профиля25записей прошла миграцию без потери этих полей.
