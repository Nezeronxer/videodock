# VideoDock 0.2.1

Исправлены восстановление прерванных загрузок YouTube, сохранение прокси и повтор старых частичных загрузок. Выбранный тип прокси больше не сбрасывается при обновлении окна; ошибки проверки видны рядом с полями, успешное сохранение закрывает настройки. Параметры и пароль сохраняются после перезапуска.

Временные ошибки YouTube запускают ограниченное обновление потока для той же записи очереди. Частичные HTTP-файлы продолжаются только при совпадении источника и выбранного формата; данные другого формата не склеиваются. Готовые файлы и история сохраняются.

Добавлена обработка открытого встроенного VideoHub-плеера на страницах сайтов. Исправлена выдача ссылок, привязанных к User-Agent. Windows-упаковщик отклоняет повреждённые EXE/DLL. Обновлены SQLite до 3.54.1 и манифест лицензий.

На Linux восстановлены 9 исходных записей ошибок с 8 разными ссылками: YouTube/Shorts, TikTok и встроенный плеер. Все 25 записей истории сохранены, пять старых повторов одной ссылки оставлены в истории. Проверены полные файлы с видео, аудио и декодированием до конца.

Работа площадок зависит от доступности видео и выбранного подключения. Прокси применяется при явном включении в настройках. Программа не обходит ограничения приватных видео, входа или DRM. Автообновление требует отдельного настроенного подписанного источника.

Состояние проверок пакетов: [отчёт выпуска](../release-2026-11-12.md).
