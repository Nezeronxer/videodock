# VideoDock 0.2.0

Настольный загрузчик видео и аудио на Rust/Qt с очередью, ручным выбором форматов, Smart Mode, субтитрами, подписками, историей и встроенным браузером.

В этом выпуске исправлены сохранение выбранных аудиоязыков при экспорте/импорте, имена субтитров при повторных загрузках и очистка результатов незавершённого сохранения. Исправлены checkbox ручного выбора при смене модели, раскрытие браузера при сохранённом фокусе адреса и идентификаторы вложенной Mac-подписи. Windows корректно измеряет длину Unicode-путей; открытие файлов на Unix больше не оставляет zombie-процессы. Подготовка обновлённого приложения сохраняет прежнюю рабочую установку при ошибке; Windows-пакет создаётся заново без устаревших DLL.

## Файлы выпуска

- Windows x64: установщик для текущего пользователя и архив приложения с Qt/FFmpeg. Установщик не имеет Authenticode-подписи доверенного издателя.
- macOS: отдельные архивы для Intel и Apple Silicon. Приложение подписано собственной подписью, без Apple notarization; это не подпись доверенного Apple Developer ID.
- Linux x86_64: Flatpak для совместимых дистрибутивов и отдельный native-архив Arch Linux. Архив Arch требует перечисленных в README системных Qt/FFmpeg и не является универсальной переносимой сборкой.
- SHA256SUMS содержит контрольные суммы опубликованных файлов. Исходники доступны в теге выпуска, тексты лицензий входят в пакеты.

## Ограничения

YouTube и Shorts могут запросить подтверждение доступа на отдельных IP и сетевых маршрутах. Приложение показывает эту ошибку и предлагает встроенный браузер/вход; успешное скачивание со всех IP не гарантируется. При проверке публичных адресов CI это ограничение учитывается отдельно от нативных тестов и сборки.

Покрытие отдельных сайтов, списков и авторизованных сценариев различается; полный паритет всех функций 4K Video Downloader+ не заявляется. Подробности - в каталоге сервисов и отчёте проверки выпуска. Обновления не устанавливаются автоматически без настроенного проверяемого источника.

Прокси применяется при явном включении в настройках приложения; системные TUN/VPN продолжают действовать через маршрут ОС. Данные и история хранятся локально, отдельно от каталога установленных файлов. При удалении записи файл сохраняется, если явно не выбран флажок удаления файла.

## Проверка

Workspace, интерфейс EN/RU и готовые пакеты проверены на native runners Windows, Linux, Mac Intel и Apple Silicon. Тот же установленный Flatpak отдельно прошёл worker/proxy/startup и проверку собственного видимого окна после настройки desktop portal в CI. Готовый Mac ARM-пакет дополнительно проверен вживую. [Подробный отчёт и границы проверки](https://github.com/Nezeronxer/videodock/blob/v0.2.0/docs/cross-platform-audit-2026-11-07.md).

`build-manifest.json` связывает исходники, производящие прогоны, отдельное подтверждение Flatpak и SHA256 шести пакетов; `SHA256SUMS` позволяет проверить скачанные файлы. Ручная матрица всех версий ОС и оборудования не заявляется.
