# VideoDock 0.2.4

Кнопка «Вставить ссылку» показывает значок YouTube, TikTok, Spotify, Vimeo, SoundCloud и других поддерживаемых сервисов, если в буфере обмена скопирована их ссылка. Для обычного текста, пустого буфера и неизвестного сайта кнопка показывает обычный значок ссылки.

Обновление доступно для Windows x64, macOS Intel и Apple Silicon, а также Linux x86_64 в пакетах Arch и Flatpak.
