# VideoDock 0.2.3

Автоматический выбор озвучки YouTube учитывает язык просмотра во встроенном браузере или параметр языка ссылки, затем системный язык. Выбор сохраняется в очереди и передаётся видео из плейлистов; ручной выбор дорожек имеет приоритет. Языковые метки готового файла соответствуют выбранному аудио.

Исправлена авторизация SOCKS5-прокси во встроенном браузере и проверке YouTube. Логин и пароль HTTP-прокси с символами `@` и `:` теперь декодируются корректно. После изменения прокси приложение явно сообщает, когда браузеру нужен перезапуск; новые загрузки используют настройку сразу.

Временный запрос YouTube «подтвердите, что вы не робот» обновляет анонимное подтверждение с ограниченным числом попыток. Он больше не приравнивается к доступу к приватному или возрастному видео.

В Windows и macOS (Intel и Apple Silicon) включена автоматическая доставка стабильных обновлений с GitHub. VideoDock проверяет версию, источник, размер и SHA-256 пакета, скачивает его в фоне и устанавливает после закрытия. Проверенный пакет сохраняется при сбое сети и восстанавливается после перезапуска. На macOS приложение дополнительно проверяет подпись пакета и возвращает предыдущую версию при сбое запуска. Автообновления можно отключить в настройках. История, настройки и скачанные видео сохраняются.

Установите 0.2.3 вручную один раз при переходе с 0.2.2 или более ранней версии. Для автоматической установки на macOS нужна папка, в которой текущий пользователь может заменить VideoDock.app. На Linux обновление устанавливается вручную.
