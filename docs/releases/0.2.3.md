# VideoDock 0.2.3

Исправлена авторизация SOCKS5-прокси во встроенном браузере и проверке YouTube. Логин и пароль HTTP-прокси с символами `@` и `:` теперь декодируются корректно. После изменения прокси приложение явно сообщает, когда браузеру нужен перезапуск; новые загрузки используют настройку сразу.

Временный запрос YouTube «подтвердите, что вы не робот» обновляет анонимное подтверждение с ограниченным числом попыток. Он больше не приравнивается к доступу к приватному или возрастному видео.

В Windows включена автоматическая доставка стабильных обновлений с GitHub. Приложение проверяет новую версию, источник, размер и SHA-256 установщика, скачивает его в фоне и устанавливает после закрытия VideoDock. Проверенный установщик сохраняется при сбое сети и восстанавливается после перезапуска. Автообновления можно отключить в настройках. История, настройки и скачанные видео остаются на месте.

Для перехода с 0.2.2 и более старых версий установщик нужно запустить один раз: в них не было работающего механизма автообновления. Следующие стабильные версии доставляются самим приложением. Автоматическая установка в этом выпуске предназначена для Windows; Linux и macOS сохраняют свои штатные способы обновления.
