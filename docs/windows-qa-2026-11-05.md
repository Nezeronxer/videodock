## Границы результата

Прямой маршрут Windows 10 оборвал соединение с видеосервером YouTube. Та же сборка с временным прокси скачала файл полностью. Это подтверждает работу приложения через проверенный маршрут, а не работоспособность любой сети, VPN или стратегии zapret. На Windows 11 длинное видео также проверено через прокси.

Для проверки сохранения профиля установщик проходил сценарий с контрольным файлом вне папки установки. Это не замена проверке всех вариантов обновления старых версий. Сохранность старой истории и медиа при удалении Media Tools дополнительно проверяется тестом `retired_media_tools`.

Во время подготовки Windows 11 обычная первоначальная настройка не могла соединиться с Microsoft. После временной настройки WinHTTP через рабочий маршрут она завершилась без обхода требований или лицензирования. Затем временные настройки WinHTTP были отменены. Проблема виртуального канала QEMU guest agent потребовала альтернативного локального транспорта для QA; его работоспособность не является свойством приложения VideoDock.

Проверки выполнены последовательно на отдельных QA-ВМ, без параллельной сборки на основной машине. Скриншоты, журналы и отчёты сохранены локально в `research/user-polish-2026-11-05` каталога данных VideoDock. Перед выпуском отдельно требуется завершить и проверить универсальную Linux-поставку.
