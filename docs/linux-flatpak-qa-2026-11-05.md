# Linux Flatpak: поставка и границы проверки

Пакет `VideoDock-0.2.0-linux-x86_64.flatpak` собран внутри KDE SDK 6.11 с Qt WebEngine BaseApp 6.11. Сборка против SDK обязательна: системный Arch-бинарь требует более новую glibc, чем runtime. В пакет входят приложение, WebEngine и лицензии; KDE runtime устанавливается Flatpak. Python, Rust и Qt SDK пользователю не нужны.

Проверена установка и настоящий интерфейс на Arch Linux/Hyprland, x86_64. На других дистрибутивах пакет пока не проверялся. Совместимый Flatpak и KDE runtime требуются; наличие единого пакета не доказывает проверку всех дистрибутивов.

## Установка

```sh
flatpak install --user ./VideoDock-0.2.0-linux-x86_64.flatpak
flatpak run io.github.Nezeronxer.VideoDock
```

Если Flatpak запросит KDE runtime, разрешите его установку из Flathub. Для последующего обновления используйте `flatpak install --user` с новым файлом. Для удаления программы с сохранением данных:

```sh
flatpak uninstall --user io.github.Nezeronxer.VideoDock
```

Не добавляйте `--delete-data`, если хотите сохранить историю и профиль. Данные Flatpak находятся в `~/.var/app/io.github.Nezeronxer.VideoDock/`; старый native-профиль автоматически не импортируется.

## Проверено

- Production release собран offline против SDK, один job, фактическая cgroup ограничена 1 ГБ без swap.
- Core/workspace, Clippy и Qt appearance: журналы `final-sandbox-verification.log` и `flatpak-production-build.log` в локальном исследовательском каталоге.
- Настоящее окно установленного пакета, настройки, видимый переключатель, добавление ссылки, полная загрузка YouTube.
- Повторный запуск 05.11: история и готовая загрузка сохранились; файл H.264 320×240 + AAC, 744 478 байт, 19,063583 с. ffprobe и полное декодирование FFmpeg с `-xerror` завершились успешно.
- Автозапуск и блокировка сна отключены в интерфейсе пакета; core отклоняет их включение до сохранения остальных настроек. Поддержка этих действий требует отдельной реализации desktop portals.

Сетевая проверка использовала существующий SOCKS-прокси. Прямой маршрут и все региональные ограничения этим не проверены. Пакет разрешает сеть, GPU, звук, оконную систему, каталог видео и доступ к host helper Flatpak для обнаружения локального VPN-прокси; это не строгая изоляция от исполнения host-команд. Можно указать прокси вручную в настройках соединения.
