## Статическая сверка оригинала

Восстановлен прежний REA bundle: `ev_762d93de83e8a2b4c943f3a5d5db2f48c99cd0e7a754d955b3cd083a683c2e0a`; повторный анализ каталога не запускался. Ресурсы сверены с локальным QRC index исходного EXE.

- ManualSubscriptionDownload объявляет Save при EditMode; footer скрывает Download Existing при редактировании. Эти действия покрываются текущим EN/RU harness.
- ManualBatchDownloadFooter заполняет меню назначения из settingsViewModel.paths. Windows кадры и harness подтверждают собственный выбор из истории.
- ManualDownloadBase делегирует доступность загрузки в modeViewModel.downloadAvailable, сохранение настроек - отдельному EditMode action. Статический QML не раскрывает всю нативную логику доступности.
- ConnectionSettings сообщает сброс ограничения скорости при перезапуске. У VideoDock это проверяют core regression и заключительная часть native harness, которая на прежней контрольной точке ещё не была пройдена; актуальный результат приведён ниже.
- Наборы threadsListModel, speedLimitsListModel и subscriptionUpdatePeriodModel приходят из нативных моделей. Последующий bounded native разбор подтвердил getter addresses, подписи и построители: [нативные настройки](native-settings-2026-11-07.md). Семантика native enums и серверный Auto всё ещё требуют проверки.

Это продолжение статической сверки и Windows QA, а не заявление о полном декомпиляционном или пиксельном соответствии. Shorts, прочие сервисные пробелы и полный парный обход остаются открытыми в основной матрице.
