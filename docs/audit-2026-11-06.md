# Проверка исправлений VideoDock, 06.11.2026

Проверяемый исходник: `3171688c3a585e51cfab7d7e300d95766efb0dce`.
Релиз 0.2.0 остаётся Draft: завершение этой проверки не означает полного паритета или отсутствия всех возможных ошибок.

## Исправления с воспроизведением

- TikTok DASH-видео ошибочно считалось содержащим звук. Парсер теперь читает отдельный `bitrateAudioInfo`, выбор форматов добавляет аудио, готовый файл проверяется. Именно ролик со скриншота скачан целиком со звуком.
- При ограничении 1080p портретное 1080×1920 ошибочно отбрасывалось; 720×1280 отображалось как 1280p. Общая оценка качества использует короткую сторону, реальные размеры сохраняются.
- Некорректная ссылка получает понятное сообщение; скрытый буфер вставки очищается и исключён из accessibility. Исправлены ширина меню, русские числительные, порядок и видимость новой задачи.
- macOS: исправлены относительные зависимости вложенного QtWebEngineProcess, комплектность Qt frameworks и запас заголовка Mach-O. Нативная упаковка, подпись и проверка запуска прошли.
- По явному выбору пользователя выключенный прокси VideoDock означает прямой маршрут ОС. Приложение не наследует HTTP-прокси окружения и системы. Явно включённый ручной прокси сохраняется, при его отказе прямого обхода нет. Настройки Happ, zapret, TUN и остальных приложений не менялись.
- Удалены поиск прокси по процессам/портам и ненужное разрешение Flatpak на запуск команд хоста.
