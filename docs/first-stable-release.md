## Изменения и проверка

Найдена и исправлена гонка повторного открытия локального профиля. На Unix закрытие последнего собственного дескриптора не снимает flock, если другой поток успел создать дочерний процесс, унаследовавший тот же open file description до exec. Поэтому после закрытия Engine следующий экземпляр иногда получал ошибку занятого профиля. Owner теперь явно освобождает блокировку после отмены фоновых операций и ожидания текущей записи состояния. Клоны Engine продолжают удерживать общего Owner.

Детерминированная регрессия с `File::try_clone` воспроизвела отказ до исправления и прошла после него. Свежая независимая проверка отдельно подтвердила поведение std::fs, исключение второго владельца при живом клоне и сохранение блокировки нового владельца после закрытия старого дубликата. Это проверка эквивалентного дублирования дескриптора, а не реального fork/exec. Предыдущий упавший cookie/restart-тест также повторён успешно.

Windows-only предупреждения в platform.rs устранены условной компиляцией Unix импортов/помощников. При настоящей Windows-упаковке обнаружен недостающий Qt6ShaderTools.dll: модуль qtshadertools добавлен в CI, установка в QA-госте завершилась успешно, DLL присутствует. Добавлен workflow нативных проверок для Linux, Windows и macOS, с read-only разрешениями и закреплённым commit checkout. Workflow не создаёт теги и релизы; статическая проверка actionlint пройдена. Результат облачного исполнения учитывается отдельно. Первоначальные два push были отклонены GitHub с Internal Server Error/fatal error in commit_refs. Затем ветка успешно отправлена; первый cloud run 41812660820 обнаружил отсутствие libvorbis в FFmpeg macOS и необходимость отключить Chromium sandbox только для root localhost fixtures Linux CI. Оба исправления отправлены. Текущий run 41843213464 проверяет коммит 602f03a; незавершённые jobs не считаются PASS.

## Пользовательский проход

Настоящий Rust/Qt бинарь управлялся Linux Sky на отдельном Xvfb-дисплее с отдельным профилем, без вмешательства в рабочий стол. Через отдельный XDG_DATA_HOME исключён локальный исследовательский appearance.rcc; проверены собственные ресурсы поставки.

Пройдены пять шагов onboarding, открыты пять разделов настроек, встроенный браузер воспроизвёл localhost MP4. Через кнопку скачивания открыт ручной диалог, введён отдельный выходной путь, получен полный файл: 51506 байт, 5.000 с, видео и аудио по ffprobe. Выбрана светлая тема и выполнено штатное закрытие; SQLite содержит light и complete-запись. Это не полный проход всего приложения. В частности, реальный вход, системные уведомления, tray и все файловые диалоги остаются отдельными сценариями. AT-SPI в этом окружении дал только корень окна; использовались свежие screenshots и настоящий ввод Sky.
