# Проверка пользовательских ошибок, 05.11.2026

Статус выпуска: **PARTIAL**. Полный релиз закрыт до проверки установщика и интерфейса на Windows 10 и Windows 11. Пользователь отложил Windows-проверку и ограничил локальные проверки 2 ГБ памяти; обе ВМ выключены, состояние Windows 11 сохранено.

## Исправления

- Ответ YouTube проверяется до чтения адреса потока. Недоступное видео, необходимость подтвердить доступ и отсутствие потока получают отдельные сообщения с дальнейшим действием. Сырые ответы сервиса в них не вставляются.
- В сохранённой истории, подписках, окне загрузки и уведомлениях технические ошибки SABR/PO token показываются понятным текстом. Исходная диагностика в хранилище сохраняется.
- Скрытые пункты подписок не оставляют пустого места перед «Удалить». Меню открывается у кнопки или места правого щелчка. «Принудительно» переименовано в «В начало очереди».
- Ползунок умного режима не исчезает при программном рендеринге: убран эффект тени, который скрывал весь слой. Видимость проверяется по пикселям в обоих состояниях переключателя.
- Просмотрены 302 русских перевода, исправлены неоднозначные подписи и несогласованные формулировки.
- Полностью полученный короткий поток ожидает подтверждения Google в пределах существующего лимита запросов. Подтверждение и полная последовательность сегментов с точным размером остаются обязательными для сохранения готового файла.

## Проверено

- Регрессии отказа YouTube, старых сообщений, привязки меню и пропавшего ползунка воспроизведены до исправлений и прошли после них.
- Rust workspace: 201 успешный тест до последнего исправления транспорта; затем полный набор core: 124 успешных теста, 0 отказов. Clippy всего workspace со всеми целями и `-D warnings` прошёл после исправления транспорта. Сетевые тесты запускаются отдельно.
- Qt: EN/RU, программный рендеринг, настройки, диалоги, меню, узкое окно, локальное скачивание, история после перезапуска и безопасное удаление записи прошли.
- Короткое видео YouTube: 742 369 байт потоков, 744 360 байт готового MP4; декодировано до конца, 19,063583 с.
- Длинное видео YouTube 720p: 181 292 478 байт потоков; декодировано до конца, 634,624 с. Этот проход выполнен перед изменением ожидания подтверждения.
- Ссылка с исходного скриншота получила отказ «Видео недоступно» и от анонимного запроса, и на странице YouTube в Chrome. Успешное скачивание этой ссылки не подтверждено.

## Осталось

- Повторный полный проход 1080p прерван после замечания о памяти; его частичный файл не считается успешной загрузкой.
- Финальная Linux-сборка установлена с резервной копией и проверена в настоящем окне. EN/RU, запуск worker, лицензии и сканирование публикуемых файлов прошли. Проверки шли последовательно с потолком 1 ГБ и без swap; наблюдаемый пик сборки около 770 МиБ.
- Windows 10: повторить проверки новой версии установщика, обновления, удаления с сохранением профиля, интерфейса и загрузки.
- Windows 11: завершить подготовку Eval-ВМ, затем выполнить те же пользовательские проверки. TPM 2.0 и Secure Boot включены. Первая установка остановилась из-за пространства имён в подготовленном XML; исправление проверено, повторная установка сохранена для продолжения.
- Полный GitHub-релиз и универсальная Linux-поставка не объявлены готовыми. Предыдущие результаты других сборок не заменяют проверку текущих артефактов.
